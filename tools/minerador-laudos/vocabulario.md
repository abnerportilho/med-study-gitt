# Vocabulário para as buscas

Combine um termo de cada coluna. Exemplo: `resultado` + `hemograma` + `pdf` + `Fleury`.

| O que é | Exame | Formato | Laboratório / origem |
|---|---|---|---|
| laudo | hemograma | pdf | Fleury |
| laudos | hemograma completo | filetype:pdf | a+ Medicina Diagnóstica |
| resultado | eritrograma | imagem | Weinmann |
| resultado de exame | leucograma | print | Alliança |
| resultados de exames | plaquetas | foto | DB Diagnósticos |
| exame de sangue | bioquímica | modelo | Hermes Pardini |
| exames laboratoriais | creatinina | exemplo | Delboni |
| análises clínicas | ureia | ilustrativo | Lavoisier |
| boletim de exames | glicose / glicemia | fictício | Sérgio Franco |
| relatório laboratorial | colesterol / lipidograma | anexo | Alta Diagnósticos |
| laudo evolutivo | TSH / T4 livre | escaneado | Sabin |
| ficha de resultado | urina tipo 1 / EAS | digitalizado | Tommasi |
| liberação de resultado | coagulograma / TAP / INR | segunda via | Unimed laboratório |
| entenda seu laudo | gasometria | site:gov.br | LACEN / GAL |
| como ler seu exame | sódio / potássio | site:edu.br | Hospital das Clínicas |
| valores de referência | ferritina / ferro | site:scribd.com | Santa Casa |
| data da coleta | vitamina D / B12 | site:passeidireto.com | Ebserh |
| material: sangue | PCR / VHS | site:slideshare.net | prefeitura / UBS |
| responsável técnico CRF | hemoglobina glicada | site:reclameaqui.com.br | laboratório municipal |
| método: automatizado | TGO / TGP | site:github.com | qualquer cidade + "laboratório" |

Variações úteis:
- Inglês: `brazilian lab report`, `blood test report portuguese`, `hemograma sample`.
- Termos de laudo que só aparecem dentro do documento: `"VR:"`, `"Valores de Referência"`,
  `"Data de liberação"`, `"Assinado eletronicamente"`, `"CRBM"`, `"CRF-"`, `"Material: Sangue"`.
- Nomes de equipamentos que aparecem no laudo: `"Sysmex XN"`, `"ABX Pentra"`, `"Cobas"`,
  `"Architect"`, `"Advia"`, `"citometria de fluxo"`.

| laudo | espirometria / prova de função pulmonar | pdf | clínica de pneumologia |
